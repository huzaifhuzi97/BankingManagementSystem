# 🏦 Banking Management System

A console-based Banking Management System developed using Core Java. This project demonstrates object-oriented programming, Java Collections, and layered application architecture.

## 🚀 Features

- **Open Account:** Create a new bank account.
- **Deposit Money:** Deposit money into an account.
- **Withdraw Money:** Withdraw money from an account.
- **Transfer Money:** Transfer money between accounts.
- **Account Statement:** View account transaction history.
- **List Accounts:** Display all registered accounts.
- **Search Accounts:** Search accounts using customer names.

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Java Collections Framework
- HashMap
- IntelliJ IDEA
- Git & GitHub

## 📂 Project Architecture

The project follows a layered architecture to separate application responsibilities.

- **Controller:** Handles user interactions.
- **Service:** Contains banking business logic.
- **Repository:** Manages account and transaction data.
- **Domain:** Contains the application's domain models.

## ⚙️ How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/huzaifhuzi97/BankingManagementSystem.git
   ```

2. Open the project in IntelliJ IDEA.

3. Configure your Java JDK.

4. Locate the main class containing the `main()` method.

5. Run the application.
